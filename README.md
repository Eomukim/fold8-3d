# FoldableSimulator — 갤럭시 Z 폴드 1~8 울트라 · 플립 전 시리즈 3D

삼성 갤럭시 Z 폴더블 **16개 모델**(폴드 1세대~폴드8 / 폴드8 울트라, 플립 1세대~플립8)을 세대별 실제 제원 그대로 절차적으로 모델링한 인터랙티브 3D 시뮬레이터입니다. 외부 모델·HDR 파일 없이 모든 형상을 코드로 생성합니다.

- 라이브: https://foldablesimulator.onrender.com

## 조작

| 조작 | 설명 |
| --- | --- |
| 시리즈 탭 `FOLD` / `FLIP` | 북 스타일(세로 접힘) / 클램셸(가로 접힘) 전환 |
| 세대 칩 `1`~`8` `Ultra` | 세대별 모델 선택 (플립은 1·3·4·5·6·7·8) |
| 드래그 · 스크롤 | 회전 · 확대 |
| 접힘 슬라이더 | 0°(접힘) ↔ 180°(펼침). 스프링 감쇠 보간 |
| `펼치기` `플렉스` `접기` | 180° / 모델별 플렉스 각(폴드 115°, 플립 95°) / 0° |
| `자동 쇼케이스` | 카메라 자동 회전 + 접힘·펼침 사이클 |
| 컬러 스와치 | 모델별 실제 컬러웨이 |
| `개요` `힌지` `카메라` `커버` | 카메라 프리셋 (플립의 `커버`는 기기를 접어서 Flex Window를 보여줌) |
| `화면 끄기` | 두 디스플레이의 발광 감쇠 |
| 키보드 | `←` `→` 접힘 각도, `Space` 자동 쇼케이스 |

## 세대별로 실제로 다른 것

형상은 모델마다 다른 파라미터로 생성됩니다.

- **두께** — 반쪽 두께가 곧 펼친 두께. 폴드 6.9mm(2019) → 4.1mm(폴드8 울트라), 플립 7.2mm → 6.1mm. 접힌 두께는 `2×반쪽 두께 + 힌지 갭`으로 계산되고, 모델마다 **힌지 쪽 두께(`tFold`)와 힌지 반대쪽 두께(`tEdge`)** 를 따로 둡니다. 3D 메시에서 실측한 값이 제원과 0.02mm 이내로 일치합니다(폴드1 17.1/15.5, 폴드2 16.8/13.8, 폴드3 16.0/14.4, 폴드4 15.8/14.2, 폴드5 13.4, 폴드6 12.1, 폴드7 8.9, 폴드8 9.7, 폴드8 울트라 8.9 / 플립1 17.3/15.4, 플립3·4 17.1/15.9, 플립5 15.1, 플립6 14.9, 플립7 13.7, 플립8 13.1mm). 세대 칩 아래 막대가 이 접힌 두께를 그대로 보여줍니다.
- **힌지 갭 · 웨지** — 1~4세대는 힌지 쪽 갭이 크고 자유단 갭이 작은 실제 웨지(폴드1 3.3→1.7mm, 폴드2 3.0→0mm, 폴드3 3.2→1.6mm, 폴드4 3.2→1.6mm, 플립3·4 3.3→2.1mm)로 접힙니다. 웨지 각도는 두 제원 두께의 차이에서 역산하므로 자유단이 벌어지지도, 파고들지도 않습니다. 5세대부터는 힌지 쪽·자유단 모두 같은 제로갭(폴드7 0.5mm, 플립8 0.9mm의 기계 유격만 남음).
- **접힘 방향** — 두 반쪽은 안쪽 면 사이의 중간면을 축으로 돌며, 움직이는 반쪽은 항상 자기 화면 쪽으로 접힙니다. 반대로 돌리면 중간 각도에서 움직이는 반쪽이 고정된 반쪽을 뚫고 지나갑니다(플립에서 실제로 그랬던 버그). 북·클램셸 모두 0°에서 접힌 두께가 제원과 정확히 같고 180°에서 이음매 간격이 0입니다.
- **힌지 커버(뒷면끼리 잇는 부분)** — 두 반쪽의 뒤쪽 면 끝단을 잇는 **현(chord) 위에 놓인 평평한 커버 플레이트**입니다. 플레이트 폭은 항상 그 현의 길이와 같아서, 접으면 접힌 두께 전체(폴드7 8.9mm)를 덮는 넓은 띠가 되고 펼치면 3mm 폭의 얇은 띠로 몸체 안에 말려 들어갑니다. 접힘각의 절반만큼 같이 회전하고, 양 끝은 후면 유리 밑으로 0.24mm만 파고들어 빛새 없이 이어지며 삐져나오지 않습니다. 띠 위에는 SAMSUNG 각인이 세로로 들어가고, 각도가 변해도 현 위에 정확히 붙어 있습니다.
- **카메라** — 아일랜드는 후면과 같은 재질의 유리를 0.7~1.1mm 들어올린 알약형 판에 가공 숄더를 준 형태이고, 그 위에 렌즈당 **검정 배럴 + 헤어라인 메탈 시트 + 가라앉은 사파이어 글라스**를 쌓았습니다. 유리 반사(env)를 낮추고 클리어코트를 줄여 이전 빌드의 하얗게 날아가던 링 하이라이트를 없앴습니다.
- **검증** — `tools/foldcheck.py`가 실제 메시 좌표로 16모델 × 7개 각도(0/30/60/90/115/150/180°)의 회전각·힌지 쪽/자유단 접힌 두께·이음매·본체/부품/힌지 상호관통을 계측합니다(112개 상태 전부 관통 0, 접힌 두께는 제원과 ±0.02mm). `tools/ladder.py`가 카탈로그를 직접 읽어 1→8 두께 사다리와 제원 일치를 검사합니다.
- **주름** — 세대별 깊이·폭이 다릅니다. 폴드1·플립1은 매우 깊고, 폴드6부터는 거의 사라지며 폴드8 울트라는 반사방지 메인과 함께 거의 보이지 않습니다. 화면 텍스처의 주름 그라디언트와 스페큘러 라인으로 표현됩니다.
- **디스플레이** — 실제 해상도·대각선에서 계산한 물리 크기(cm)와 비율로 패널을 만듭니다. 폴드1의 4.6" 커버, 폴드2~5의 23.1:9 6.2", 폴드6의 6.3" 22.1:9, 폴드7·8 울트라의 6.5" 21:9, 폴드8의 5.5" 22.7:9 커버와 4:3 7.6" 메인, 플립5·6의 3.4" 폴더형, 플립7·8의 4.1" 엣지투엣지. 커버 패널은 더 이상 80%로 잘리지 않고 제원 크기 그대로 들어갑니다(폴드6 14.8cm).
- **카메라 배치** — 폴드1 가로 블록(3렌즈+플래시) / 폴드2 세로 범프 / 폴드3·4 세로 알약 / 폴드5 플로팅 플래시 / 폴드6·7 슬림 링 + 바깥 플래시 / 폴드8 듀얼 + 알약 안쪽 플래시 / 폴드8 울트라 200MP 모듈. 아일랜드는 힌지에서 먼 쪽(외곽 레일 쪽)에 붙고, 상단에서 약 3cm 내려온 위치 — 실물 사진 기준입니다. 플립은 1.1" 필, 바이저 밴드, 폴더 윈도우, 엣지투엣지 윈도우 레이아웃.
- **모서리** — 세대별 외곽 반경을 따로 둡니다. 폴드6·7·8·8 울트라는 S24 울트라처럼 거의 각진 모서리(2.4~3.0mm), 폴드1·플립1은 크게 둥근 모서리, 그 사이 세대는 중간값. 본체는 외곽선을 그대로 압출한 45° 샤퍼 슬래브라 치수가 정확하고 레일 모서리에 또렷한 하이라이트가 섭니다.
- **디테일** — 안테나 밴드, SIM 트레이 슬롯, 스피커 그릴·마이크 핀홀, 측면 키 홈과 지문 키, 카메라 아일랜드의 가공 립과 총알형 배럴·광택 샤퍼, 후면 각인, 힌지 스파인의 SAMSUNG 각인, UDC·펀치홀·노치 내부 카메라.

## 스택

React 19 + Vite 7 + three 0.180 + `@react-three/fiber` 9 + drei 10 + postprocessing.
PMREM 스튜디오 환경(Lightformer 9개, 네트워크 없음), ACES 톤매핑. 데스크톱은 Bloom + SMAA + ContactShadows 포스트패스, 모바일은 포스트패스 없이 단일 패스로 그립니다.

```
src/lib/models.js      세대별 제원·색상·카메라·주름 데이터
src/lib/textures.js    캔버스로 그리는 메인/커버 디스플레이와 재질 맵
src/scene/DeviceModel.jsx  파라미터 기반 기기 생성(북/클램셸)
src/scene/parts.jsx    카메라 아일랜드 · 플립 커버 클러스터
src/ui/HUD.jsx         시리즈/세대 선택, 제원, 접힘 슬라이더, 컬러, 카메라 프리셋
src/lib/perf.js        화면 크기·포인터로 고르는 렌더 예산(데스크톱 / 모바일)
```

## 성능 — 데스크톱 / 모바일 두 단계

같은 모델·재질·조명을 쓰되 GPU 예산만 다르게 잡습니다(`src/lib/perf.js`). 터치 포인터이거나 폭이 좁으면 모바일 단계입니다. `?perf=low` / `?perf=high`로 강제할 수 있습니다.

| | 데스크톱 | 모바일 |
| --- | --- | --- |
| 픽셀 비율 | 최대 2.0 | 최대 1.25 |
| 포스트패스 | SMAA + Bloom + ACES | 없음 (캔버스 MSAA + 렌더러 ACES) |
| 환경맵 | PMREM 256 | 128 |
| 화면 텍스처 | 1400px / 700px | 약 0.66배 |
| 곡선 분할 | 24~56 | 8~32 |
| 접지 그림자 | ContactShadows 1024 | 바닥 자체 그라디언트 |
| 유리 패널 | `backdrop-filter` | 불투명 유리(합성 비용 제거) |

접힘 슬라이더는 프레임마다 React를 다시 그리지 않고 Three 회전과 DOM 판독값만 갱신합니다. 기기 형상·재질·화면 아트는 두 단계에서 동일합니다.

## 개발 / 빌드

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview
```
