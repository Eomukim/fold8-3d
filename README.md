# Galaxy Z Fold 8 — 3D 쇼케이스

React + Vite + Three.js(`@react-three/fiber`, `@react-three/drei`)로 만든 **Galaxy Z Fold 8 컨셉** 인터랙티브 3D 프로덕트 쇼케이스입니다. 폴더블 폰을 절차적으로(procedural) 모델링했고, 접힘 각도·컬러웨이·카메라 프리셋을 직접 조작할 수 있습니다.

## 조작

| 조작 | 설명 |
| --- | --- |
| 드래그 | 모델 회전 (OrbitControls) |
| 스크롤 / 핀치 | 확대·축소 |
| 접힘 슬라이더 | 0°(접힘) ↔ 180°(펼침). 스프링 감쇠로 부드럽게 이어집니다 |
| `펼치기` `플렉스` `접기` | 180° / 115° / 0° 프리셋 |
| `자동 쇼케이스` | 카메라 자동 회전 + 접힘·펼침 사이클 |
| 컬러 스와치 | 타이타늄 그레이 · 실버 섀도 · 크래프티드 블랙 · 딥 네이비 |
| `개요` `힌지` `카메라` `커버` | 카메라 프리셋(부드러운 이동) |
| `화면 끄기` | 두 디스플레이의 발광을 감쇠시켜 실제 화면 꺼짐처럼 연출 |
| 키보드 | `←` `→` 접힘 각도, `Space` 자동 쇼케이스 |

## 모델링 노트 (전부 코드로 생성, 외부 모델 파일 없음)

- **두 개의 반쪽 섀시** — 둥근 모서리가 다른 `ExtrudeGeometry` + 베벨(샤모퍼)로 깎은 금속 프레임. 각 반쪽 두께 4.2 mm, 바깥 모서리 R5.2, 힌지 쪽은 거의 직각.
- **정밀 힌지 스파인** — 원통 배럴 + 테이퍼 캡 + 5개의 너클 링과 홈. 힌지 축은 앞면 유리 바로 위에 두어 두 디스플레이가 책처럼 정확히 맞닿고, 어떤 각도에서도 관통이 없습니다. 힌지 디테일은 접힘 각도의 절반만큼 회전합니다.
- **듀얼 디스플레이** — 캔버스로 그린 1680×2240 내부 AMOLED 텍스처(시계·날씨·일정·독·주름)와 760×2000 커버 텍스처(락스크린). 내부 화면은 좌우 반쪽이 하나의 텍스처를 UV로 나눠 이어 그리므로 접힘선이 끊기지 않습니다.
- **후면 트리플 카메라** — 상승한 플래토, 3개의 머시닝 링, 사파이어 글래스 돔, LED 플래시.
- **디테일** — 스피커 그릴(인스턴싱), USB-C 컷아웃, SIM 트레이, 안테나 밴드, 음량·전원 버튼, 후면 각인 워드마크.
- **스튜디오 조명** — `Lightformer`로 구성한 PMREM 환경(네트워크 HDR 없음), ACES 톤매핑, ContactShadows, Bloom·SMAA 후처리.

## 개발 / 빌드

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview
```

## 배포

`render.yaml`(Render Blueprint) 또는 Render 대시보드에서 **Static Site**로 배포합니다.

- Build Command: `npm ci && npm run build`
- Publish Directory: `dist`

## 참고

Galaxy Z Fold 8은 아직 발표되지 않은 컨셉 제품입니다. 이 저장소는 팬 메이드 3D 데모이며 삼성전자와 관련이 없습니다. 상표는 각 소유자의 것입니다.
